# منصة المؤسسات

تطبيق Flutter لمنصة عامة للمؤسسات، مرتبط بباك إند Spring Boot.

## ما تم تغييره

- إزالة الصلاة والقبلة والقرآن والأذكار والمسبحة وحساب الموقع المرتبط بالمواقيت.
- تحويل الواجهة الرئيسية إلى الإعلانات والفعاليات ومعلومات المؤسسة.
- تحويل شاشة التلفاز إلى شاشة ترحيب بالمؤسسة مع تدوير صور الإعلانات.
- عرض الفعاليات القادمة بتاريخها ووقتها من دون عدّاد تنازلي.
- إضافة إدارة الفعاليات لمسؤول المؤسسة.
- إضافة معلومات المؤسسة: النوع والوصف والعنوان وبيانات التواصل والشعار.
- استخدام مسارات المؤسسات الجديدة (`/api/institutions`) وصلاحية `INSTITUTION_ADMIN`.
- إبقاء دعم `MOSQUE_ADMIN` فقط للحسابات القديمة الموجودة مسبقًا في قاعدة البيانات.

## التشغيل

على المحاكي:

```powershell
flutter pub get
flutter run -d emulator-5554
```

على هاتف أو تلفاز حقيقي، مرّر عنوان الحاسوب الذي يعمل عليه Spring Boot:

```powershell
flutter run -d DEVICE_ID --dart-define=API_BASE_URL=http://COMPUTER_IP:8080
```

يجب تشغيل نسخة الباك إند المرفقة مع هذه النسخة من Flutter لأن مسارات الـAPI تغيّرت.
